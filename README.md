## Featured Projects

### 🔎 Perplexity Clone

A full-stack AI search engine exploring real-time AI interactions, chat-scoped RAG, tool orchestration, multimodal document ingestion, authentication, and model failover.

**What makes it interesting:**

* Real-time AI response and tool-status streaming with Socket.IO
* Chat-scoped RAG isolation using Pinecone + MongoDB
* LangChain-based agent and tool orchestration
* Multimodal document ingestion with isolated fallback pipelines
* Guest-to-user session migration and authentication
* Automated integration testing and API documentation generation

**Stack:** React · Node.js · Express · MongoDB · Redis · Pinecone · Socket.IO · LangChain · Gemini · Mistral

→ **[Explore the project](https://github.com/aryanpatel287/peplexity-clone)**
→ **[Live Demo](https://perplexity.aryanpatel.in)**

### 🛍️ Sciolto

A full-stack streetwear e-commerce platform focused on the engineering challenges behind catalog querying, variant-level inventory, checkout consistency, client-side caching, authentication, and media delivery.

**What makes it interesting:**

* MongoDB transactions for atomic inventory updates during checkout
* Server-side catalog filtering, sorting, and pagination
* Redux-based client-side page caching with invalidation
* Dynamic product variants with independent inventory and pricing
* Redis-backed JWT invalidation
* CDN-backed image upload and delivery

**Stack:** React · Node.js · Express · MongoDB · Redis · Redux Toolkit · ImageKit · Razorpay · Vitest

→ **[Explore the project](https://github.com/aryanpatel287/sciolto)**
→ **[Live Demo](https://sciolto.aryanpatel.in)**
